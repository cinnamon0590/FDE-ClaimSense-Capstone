# ClaimSense security mapping: OWASP Top 10 for LLM Applications (2025)

Each risk is mapped to the control that addresses it in M2, the test or evidence that proves the
control works, and what is still open. Every control named here runs in code. G1b is the one
model-based check, and it can only escalate to a human (D-026).

| # | OWASP risk | ClaimSense control | Proof | Residual / next |
|---|---|---|---|---|
| LLM01 | **Prompt injection** (direct and indirect) | **G1** regex scan on 3 views (raw, normalised, skeleton) plus base64 decode. **G1b** classifier on PII-masked text *before* the model sees it. Injected text is removed or withheld. Intake tripwire hands the claim to a senior adjuster. Decision tripwire rejects a draft that repeats instruction-like text | `tests/test_guardrails_tripwires.py`, `tests/test_guardrail_fuzz.py` (fuzz 99.9%, 0 false positives); held-out v3: 13/15 caught with G1 + G1b ([`evidence/guardrail-fuzz.txt`](evidence/guardrail-fuzz.txt)); CS-016, CS-035 | Held-out sets are small. M3: 100+ red-team set, track the catch rate per release |
| LLM02 | **Sensitive information disclosure** | **G3** PII masking (names, email, phone, SSN, VIN, card; Unicode-normalised) before prompts, traces and cards. **G7** masks other claims' IDs on input and redacts them on output. Entitlement checked before any data is read. `trace_include_sensitive_data=False` | `test_pii_never_reaches_the_model_traces_or_card`, `test_decision_leaking_another_claim_is_redacted`, `test_unentitled_user_gets_nothing_and_no_agent_runs`; CS-017, CS-036, CS-039 | M3: Cognito JWT replaces the `X-User-Id` header |
| LLM03 | **Supply chain** | Pinned dependency versions (`requirements.txt`), pinned model snapshots (D-025), pinned base images and Lambda adapter tag, immutable image tags (commit SHA). CI scans each image with Trivy and publishes an SBOM; a critical CVE that has a fix blocks the push | `.github/workflows/eval-gate.yml` (`supply-chain` job) | Dependabot alerts on the repo (M3) |
| LLM04 | **Data and model poisoning** | **G2** provenance quarantine: a retrieved chunk whose hash is not in the clause manifest never reaches the model. Every version of a clause is retrieved, so a poisoned copy can't hide the real one | `test_poisoned_chunk_is_in_the_index_but_never_returned`, `test_manifest_hashes_match_the_clause_text`; CS-020, CS-040 | Manifest signing (KMS) when the corpus moves to S3 in M3 |
| LLM05 | **Improper output handling** | Strict Pydantic `output_type` (`extra="forbid"`) for every agent. Each card is validated against the M1 DecisionCard schema in the pipeline **and again at the boundary**, and the boundary re-derives the money (D-024). Citation quotes are overwritten with the retrieved text | `test_strict_parsing_rejects_a_malformed_model_output`, `test_boundary_rejects_a_draft_that_is_not_a_valid_card_for_this_claim`, `test_citation_quotes_are_the_retrieved_wording_not_a_paraphrase` | None known |
| LLM06 | **Excessive agency** | Agents have read-only tools (`get_claim_file`, `search_clauses`) and no write, pay or confirm tool. Confirmation is human-only at the boundary, **even when an agent acts on behalf of a human** (D-024). **G6** forces adjuster confirmation. Code orchestrates a fixed sequence (no model-chosen handoffs) | `test_an_agent_acting_for_a_human_cannot_confirm`, `test_forced_auto_decision_keeps_the_verdict_but_requires_an_adjuster`; stack smoke: agent confirm refused | None known |
| LLM07 | **System prompt leakage** | Prompts hold no secrets, keys or customer data (they are in the public repo by design). Refusals and errors never echo prompts. Guardrail reasons report counts, never the injected text | `test_injection_text_never_reaches_the_model`; D-020 | None known |
| LLM08 | **Vector and embedding weaknesses** | The index is built only from the manifest-checked clause corpus; the provenance check runs on every retrieval. Per-request `retrieved_clause_ids` scope citations (**G5**). No user text is ever written to the index | `test_coverage_citing_an_unretrieved_clause_trips`, `test_decision_citing_an_invented_clause_trips_and_is_withheld`; CS-040 (citation forgery) | OpenSearch per-tenant index policies (M3) |
| LLM09 | **Misinformation** (hallucination, over-reliance) | Code owns facts and numbers (**G4**, verified facts). Every coverage decision must cite retrieved clauses (**G5**). A second-opinion Decision Draft: disagreement goes to a human (**G8**). `verdict_source` separates model from fallback. A licensed adjuster confirms every outcome | `test_code_owns_the_money_whatever_the_model_says`, `test_disagreeing_drafts_go_to_a_senior_adjuster`; release gate: 3 live runs ([`evidence/results-live-stability.txt`](evidence/results-live-stability.txt)) | Track the adjuster override rate in production (M4) |
| LLM10 | **Unbounded consumption** | Per-claim budget cap (`CASE_BUDGET_USD=0.05`) raises and falls back. `max_turns=10`. Model routing (mini for volume steps). Live CI runs only the 20-case smoke suite. Every run reports tokens and cost | `BudgetExceeded` in `claimsense/pipeline.py`; [`evidence/cost-table-live.md`](evidence/cost-table-live.md) | API Gateway throttling and an AWS Budgets alarm (M1 provisioned the alarm) |
